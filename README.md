# Piniverse

> 一个由**平级 Pi 会话**组成的 Agent 网络：没有制度上的子代理，只有消息、契约与自发组织的协作。

Piniverse 基于 [Pi](https://github.com/earendil-works/pi)（`@earendil-works/pi-coding-agent`）构建。它只引入一个新原语——**跨会话消息**：所有 agent 都是能力完全相同的对等会话，委托、汇报、转向、取消全部是消息；"主代理/子代理"不是任何会话的身份，而是两个对等体之间随任务生灭的**任务契约**。任务执行过程中，网络由这些契约自发组织而成，任务结束即解体——深度无制度上限，拓扑随任务自适应，全程留痕可重放。

三条核心命题（详见 [00 愿景](docs/00-vision.md)）：

1. **对等**——所有会话同配置、同能力、同一份 system prompt，无"你是子代理"设定；
2. **消息是唯一协调原语**——基础设施只做无决策的搬运与记账；
3. **主从关系是涌现的契约**——双边同意建立、权利有界、随时可解除、状态由消息日志推导。
